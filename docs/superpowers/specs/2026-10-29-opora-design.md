# Опора — замысел первой версии

Дата: 29.10.2026. Согласовано с владельцем в чате («Давай»).

## Зачем

Личное Android-приложение владельца, чтобы бросить порно, навязчивую мастурбацию,
бесконечный скроллинг лент и другие привычки, которые он сам добавит.

**Сказал владелец:** избавиться от порно, мастурбации, скроллинга и других плохих
привычек; как именно — решать мне.

**Предположения (владелец не возражал):** приложение для одного человека, ставится
из APK, не из Play Маркета; интерфейс на русском; Android 8.0+ (API 26); все данные
только на телефоне, без аккаунтов и интернета.

**Успех:** реже срывы и меньше минут в лентах, а не красивые графики. Каждая функция
должна либо ставить паузу между импульсом и действием, либо помогать пережить тягу,
либо показывать, откуда она берётся.

## Принципы

1. **Пауза, а не тюрьма.** На Android защиту всегда можно снять в системных
   настройках. Задача — замедлить импульсивное решение. Ослабить защиту можно,
   но только после ожидания (по умолчанию 15 минут).
2. **Без стыда.** Срыв не обнуляет прогресс: лучший результат и общее число чистых
   дней остаются. Вина после срыва — частая причина следующего (эффект нарушения
   воздержания, Марлатт).
3. **Приватность.** Нет разрешения INTERNET. Данные — один JSON-файл во внутренней
   памяти приложения. Нейтральное название «Опора» и иконка. По желанию PIN на вход.

## Что входит

### 1. Сторож (AccessibilityService)

- **Сайты 18+.** В браузерах и поисковых приложениях читается адресная строка,
  поле поиска и заголовок окна. Совпадение со списком доменов, «взрослыми» доменами
  первого уровня (.xxx, .porn, .sex, .adult) или словами → телефон уходит на
  главный экран, поверх — экран «Закрыто» с кнопкой «Тяга». Работает и в инкогнито.
  Свои слова для блокировки и слова-исключения задаются в настройках.
- **Ленты.** Список отслеживаемых приложений (по умолчанию из установленных: TikTok,
  YouTube, Instagram, VK, VK Клипы, Likee, Telegram — Telegram выключен по умолчанию,
  остальные включены, если установлены). Для каждого:
  - пауза перед открытием: 10 секунд дыхания, сколько раз уже открывал сегодня
    и сколько минут провёл, кнопки «Не открывать» и «Открыть на 5 / 15 минут».
    Когда отведённое время кончилось — пауза снова;
  - дневной лимит минут (нет / 15 / 30 / 60 / 120); после лимита — закрыто до утра;
  - «закрыто всегда»;
  - «закрыто ночью».
- **Разделы внутри приложений:** YouTube Shorts и Instagram Reels распознаются по
  идентификаторам элементов экрана. Правила те же, что для приложения, но «уйти»
  значит «назад», а не «на главный экран». Распознавание зависит от версий YouTube и
  Instagram и может ломаться после их обновлений.
- **Ночной режим:** по умолчанию 23:00–07:00, ленты с «закрыто ночью» не открываются.
- **Ослабление защиты:** выключить сторож, фильтр 18+, ночной режим, убрать
  приложение, увеличить лимит, сократить паузу или задержку, добавить исключение —
  только в окне 10 минут, которое открывается через N минут после нажатия
  «Ослабить защиту» (N: 5 / 15 / 30 / 60, по умолчанию 15). Ужесточать можно сразу.
- **Учёт времени** в лентах ведёт сам сторож по смене активного окна и выключению
  экрана. Хранится 60 дней. Отдельное разрешение на статистику использования
  не нужно.

### 2. Тяга

Кнопка на главном экране и плитка в шторке. Экран: таймер 10 минут, дыхание
«квадратом» (4 с вдох, 4 задержка, 4 выдох, 4 задержка), причины бросить, которые
владелец написал сам, список быстрых действий. В любой момент — «Тяга прошла» или
«Сорвался». Затем причина: скука, стресс, одиночество, усталость, ночь в кровати,
увидел в ленте, другое. «Сорвался» добавляет срыв выбранной привычке.

### 3. Привычки

Порно, мастурбация, скроллинг — на выбор при первом запуске, плюс свои. На карточке:
текущая серия (дни и часы с последнего срыва или начала), лучшая серия, всего чистых
дней (календарные дни без срыва с начала), кнопка «Срыв» (с подтверждением и
причиной). Привычку можно переименовать и удалить.

### 4. Статистика

Тяги за 30 дней: сколько прошло, сколько срывов; распределение по часам суток; по
причинам. Минуты в лентах за 7 дней по дням и по приложениям. Короткие подсказки по
данным, например «Чаще всего тянет с 23 до 1 часа — включите ночной режим раньше».

### 5. Настройки

PIN на вход (4–8 цифр, хранится солёный SHA-256), свои слова для блокировки,
исключения, причины бросить, удаление всех данных (с подтверждением).

## Не входит в первую версию

Фильтр DNS через VPN для всех приложений (конфликтует с VPN владельца), партнёр для
отчётов, виджет, уведомления, синхронизация, защита от удаления приложения.

## Устройство

```
opora/
  core/   — чистый Kotlin/JVM, отдельная сборка (includeBuild). Вся логика и модель
            данных, тесты на JUnit. Собирается без Android SDK.
  app/    — Android: сторож, экраны Compose, хранилище, плитка.
```

**core** (каждая часть — отдельный файл с одной задачей):

| Часть | Что делает |
|---|---|
| `model/` | `AppState` и всё, что в нём хранится (`@Serializable`) |
| `Streaks` | серии и чистые дни по привычке |
| `AdultContentDetector` | есть ли в строке сайт 18+ |
| `NightSchedule` | попадает ли время в ночной интервал (через полночь тоже) |
| `GuardPolicy` | решение для активного приложения или раздела: пропустить / пауза / закрыть и почему |
| `UsageTracker` | учёт секунд по приложениям и дням по событиям «окно сменилось», «экран выключен» |
| `Loosening` | ослабляют ли новые настройки защиту; окно разрешения |
| `Stats` | цифры для экрана статистики и подсказки |
| `StateStore` | загрузка и сохранение `AppState` в JSON; битый файл не теряется |
| `PinHash` | соль и SHA-256 для PIN |

**app:**

| Часть | Что делает |
|---|---|
| `OporaApp` | загружает состояние при старте |
| `data/Repository` | `StateFlow<AppState>`, атомарная запись файла в фоне, сессионные разрешения «открыть на N минут» |
| `guard/GuardService` | AccessibilityService: определяет активное приложение, читает адрес в браузерах, ищет Shorts/Reels, спрашивает `GuardPolicy`, показывает паузу или закрывает |
| `guard/InterceptActivity` | экраны «Пауза» и «Закрыто» поверх других приложений |
| `guard/UrgeTileService` | плитка «Тяга» в шторке |
| `ui/` | вкладки «Главная», «Сторож», «Статистика», «Настройки», экран «Тяга», первый запуск, PIN |

Поток: `GuardService` получает событие → определяет цель (приложение или раздел) →
`UsageTracker` учитывает время → `GuardPolicy.decide(цель, время, состояние,
разрешения)` → ничего / `InterceptActivity` с паузой / «на главный» или «назад» +
`InterceptActivity` «Закрыто». Пока лента на экране, сторож перепроверяет решение
каждые 15 секунд (лимит, конец разрешения, начало ночи).

**Стек:** Kotlin 2.0.21, AGP 8.7.3, Gradle 8.9, Compose BOM 2024.12.01, Material 3,
kotlinx.serialization 1.7.3, coroutines. Без Room и без навигационной библиотеки.

## Ошибки и сбои

- Нечитаемый файл состояния переименовывается в `state.broken-<время>.json`,
  приложение стартует с пустым состоянием и говорит об этом на главном экране.
- Запись файла: во временный файл, затем переименование.
- Сторож не падает на `null` от системы (окно, узлы, текст); обход дерева
  ограничен 400 узлами.
- Нет разрешения спецвозможностей — вкладка «Сторож» показывает, как включить,
  включая «Разрешить ограниченные настройки» на Android 13+.

## Проверка

- `core`: модульные тесты на всё в таблице выше, запускаются здесь и в CI.
- `app`: собирается только в GitHub Actions (в облачной сессии закрыт
  `dl.google.com`). Проверка на телефоне — у владельца.
- CI на каждый пуш: тесты `core`, сборка подписанного APK, на `main` — Release
  с APK. Подпись одним ключом, чтобы обновления ставились поверх без потери данных.
