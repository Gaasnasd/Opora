# Опора v1 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** первое устанавливаемое APK «Опоры»: сторож (сайты 18+, ленты, лимиты, ночь), экран «Тяга», счётчики привычек, статистика, PIN.

**Architecture:** вся логика — чистый Kotlin в отдельной сборке `core/` (подключена в корень через `includeBuild`), тестируется без Android SDK. `app/` — тонкий Android-слой: AccessibilityService, экраны Compose, файл состояния. Решения сторожа принимает `GuardPolicy` из `core`, сервис только собирает факты и выполняет решение.

**Tech Stack:** Kotlin 2.0.21, Gradle 8.9 (wrapper), AGP 8.7.3, compileSdk/targetSdk 35, minSdk 26, Java 17, Compose BOM 2024.12.01 + Material 3, kotlinx-serialization-json 1.7.3, kotlinx-coroutines 1.9.0, JUnit через `kotlin("test")`.

**Spec:** `docs/superpowers/specs/2026-10-29-opora-design.md`

## Global Constraints

- Пакет и applicationId: `app.opora`; логика — `app.opora.core`.
- Нет разрешения `INTERNET` и других опасных разрешений. `allowBackup="false"`.
- Весь текст интерфейса — по-русски, обращение на «вы», без стыда за срыв.
- Ослабление защиты — только в окне 10 минут, которое открывается через `looseningDelayMin` (5/15/30/60, по умолчанию 15) после запроса. Ужесточение — сразу.
- Значения по умолчанию: пауза 10 с; ночь 23:00–07:00; разрешение «открыть» на 5 или 15 минут; таймер тяги 10 минут; дыхание 4-4-4-4; учёт времени — 60 дней; тяг хранится не больше 2000.
- Обход дерева экрана в сторожe — не больше 400 узлов; сторож не падает на `null`.
- `app/` в облачной сессии не собирается (закрыт `dl.google.com`) — компиляция проверяется в GitHub Actions. `core/` — локально: `./gradlew -p core test`.

## Review Focus

1. Часы телефона перевели назад (срыв «в будущем») — серии не уходят в минус, показывается 0. → тест в Task 2.
2. Битая URL-кодировка и очень длинная строка из браузера (`%E0%A4%A`, 100 000 символов) — детектор не бросает исключение. → тест в Task 3.
3. Сторож получает подряд одно и то же активное приложение (свой экран паузы, шторка, клавиатура) — время не удваивается, «открытия» не множатся. → тест в Task 5.
4. Правило удалили, пока действует разрешение «открыть на 5 минут» — решение `Allow`, без падения. → тест в Task 4.
5. Файл состояния от другой версии (лишние или недостающие поля) читается без потери данных. → тест в Task 1.

**Interfaces — Consumes:** `GuardPolicy`, `KnownTargets`, `UsageTracker`, `AdultContentDetector`, `Repository`. **Produces:** `GuardService.instance: GuardService?`, `fun leave(targetId: String)`, `fun isEnabled(context: Context): Boolean`; `InterceptActivity.pause(context, targetId)`, `InterceptActivity.block(context, label: String?, reason: BlockReason)`.

Поведение: свой пакет, `com.android.systemui` и клавиатуры не меняют активную цель. `TYPE_WINDOW_STATE_CHANGED` задаёт активный пакет; для YouTube/Instagram цель уточняется `section(...)` по id узлов (не чаще раза в 700 мс); в браузерах тексты полей ввода, адресной строки (id с `url`, `address`, `omnibox`, `location`, `search`) и заголовок окна идут в `adultMatch` (не чаще раза в 500 мс). Решение: `Pause` → `InterceptActivity.pause` (не чаще раза в 3 с на цель); `Block` → «назад» для раздела, «домой» для приложения и сайта, затем `InterceptActivity.block`. Пока цель на экране — перепроверка каждые 15 с. Выключение экрана закрывает сессию учёта.

- [ ] **Step 1:** Реализовать. **Step 2:** `./gradlew -p core test` PASS; компиляция в CI. **Step 3:** Commit «Сторож».
